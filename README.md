📊 Abstract

Problem: The $\Lambda$CDM model predicts smooth structure evolution from Gaussian initial conditions.

Method: Bispectral analysis of velocity dispersion (VDISP) in 2.8M SDSS DR17 galaxies and 1.4M DESI LRG galaxies using a corrected open-source Rust/Python pipeline.

Finding: The analysis reveals a non-Gaussian signal incompatible with $\Lambda$CDM
